# Mandarin Tone Writer

A standalone web app for typing Chinese characters and seeing their Mandarin tones color-coded.

## Tone colors
- 1st tone: blue
- 2nd tone: green
- 3rd tone: purple
- 4th tone: red
- Neutral/unknown: gray

## Dictionary
The current version loads CC-CEDICT in the browser for broad word-level pronunciation coverage and keeps a character-level fallback for additional Hanzi.

## Run locally
Open `index.html` in a browser. For best PWA/install behavior, serve the folder from a local or web server rather than opening it directly as a file.

## Publish as a website
Upload the contents of this folder to GitHub Pages, Netlify, Vercel, or another static hosting service.
